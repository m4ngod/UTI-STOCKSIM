# UTI-STOCKSIM Docs 导航

本文档用于帮助快速定位 `docs/` 目录下的文档。

---

## 1. 一级指导文档（位于 `docs/` 根目录）

这些文档跨模块、跨阶段，适合作为总导航和总原则保留在根目录：

- `docs-organization-rules.md`：docs 目录整理规则
- `chief-engineer-handover.md`：总工程师接管文档
- `first-executable-backlog.md`：第一批可执行 backlog
- `rollout_plan.md`：项目收束路线图
- `decision-log.md`：关键决策记录
- `project-memory.md`：项目长期记忆
- `code-index.md`：代码索引

---

## 2. 分类目录

### `contracts/`
用于放置数据契约、页面契约、语义契约。

当前示例：
- `contracts/market/market-detail-contract.md`

### `tasks/`
用于放置模块任务文档、分阶段执行文档、具体推进方案。

建议后续优先把新任务文档放到这里。

### `testing/`
用于放置测试矩阵、测试策略、验证说明。

建议后续把 runtime critical path test matrix 放到这里。

### `architecture/`
用于放置前端、runtime、integration、storage 等架构文档。

### `data/`
用于放置存储设计、数据分层、表规划、run context 等数据演进文档。

### `current-work-status/`
用于放置模块级续接状态记录。

当前典型文件：
- `current-work-status/market-detail.md`
- `current-work-status/account.md`
- `current-work-status/engine.md`
- `current-work-status/mainwindow.md`
- `current-work-status/compat-retirement.md`

简述如下：

- `docs/` 根目录：一级指导文档
